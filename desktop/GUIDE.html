1. 這是什麼

career-ops 是一套用 AI 助手管理求職的工具。AI 助手（Codex、Claude Code、Gemini CLI 等）在終端機裡評估職缺、產生客製化履歷、掃描公司招聘頁。桌面版把這些資料用視覺介面呈現，不用打指令就能瀏覽、篩選、追蹤申請。

兩者搭配使用，各司其職：

你現有的履歷、cover letter、論文、研究成果，都可以整理進 cv.md。career-ops 讀這些資料來替你客製化每份申請。

2. 安裝準備

桌面 app 目前只支援 macOS。需要四個工具，打開「終端機」（Spotlight 搜尋 Terminal）逐一安裝。

  • 0
    Homebrew（套件管理器）
    Mac 上裝開發工具最方便的方式。如果已經裝過可以跳過。
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
  • 1
    Go 1.24+
    桌面 app 的資料層用 Go 寫成。
brew install go
  • 2
    Node.js 22+
    前端介面用 React 寫成，需要 Node。
brew install node
  • 3
    Rust 1.96+
    Tauri 框架的底層，負責把 app 包成原生視窗。
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

安裝過程會問你要不要用預設設定，按 Enter 選預設即可。裝完後關掉終端機再重新開，讓 cargo 指令生效。

  • 4
    Xcode Command Line Tools
    macOS 編譯原生程式碼的基礎工具。
xcode-select --install

裝完後可以用以下指令確認版本：

go version     # go1.24.x 以上
node -v        # v22.x 以上
cargo --version # 1.96.x 以上

3. 設定你的資料

career-ops 用幾個文字檔認識你。設定好這些檔案，AI 助手才能替你客製化履歷和評估職缺。桌面 app 也讀同一組資料。

你不用自己編輯這些檔案。在終端機裡開 Codex，把下面的 prompt 貼進去，Codex 會問你問題、讀你的文件、幫你全部設好。

資料夾結構

以下是你會用到的檔案。標記 你填 的需要你自己編輯，標記 自動 的由工具產生。

career-ops/ ├── cv.md ← 你的履歷（必填） ├── config/ │ └── profile.yml ← 姓名、目標職位、薪資（必填） ├── portals.yml ← 要掃哪些公司（建議填） ├── modes/ │ └── _profile.md ← 個人化設定（自動從範本產生） ├── data/ │ └── applications.md ← 追蹤表（工具自動維護） ├── reports/ ← 評估報告（每次評估自動產生） ├── output/ ← 產出的 PDF 履歷 └── desktop/ ← 桌面 app 本體

用 Codex 一次搞定

在終端機裡進入 career-ops 資料夾，啟動 Codex：

cd career-ops
codex

Codex 開好後，貼上以下 prompt。把 ~/Documents/求職資料/ 換成你放履歷、cover letter、論文的資料夾路徑：

我要設定 career-ops。我的履歷、cover letter、論文等文件
在 ~/Documents/求職資料/ 這個資料夾裡。

請讀取那個資料夾的內容，幫我建好以下四個檔案：

1. cv.md — 從我的文件整理出 Markdown 格式的履歷，
   包含：簡介、經歷、學歷、發表與研究、技能。
   如果論文很多，另外建 article-digest.md 放精簡摘要。

2. config/profile.yml — 從 config/profile.example.yml 複製。
   問我：姓名、email、所在地、時區、
   目標職位（可多個）、期望年薪範圍和幣別，填入後讓我確認。

3. portals.yml — 從 templates/portals.example.yml 複製。
   根據我的目標職位更新 title_filter.positive 的關鍵字。

4. modes/_profile.md — 如果不存在就從
   modes/_profile.template.md 複製。

每建好一個檔案，跟我確認內容再繼續下一個。

沒有現成文件？不用準備資料夾也行。把 prompt 第一段的路徑刪掉，Codex 會直接問你的經歷、學歷、技能，從頭幫你寫 cv.md。

Cover letter 不用事先準備。career-ops 的 AI 助手會根據你的 cv.md 和每個職缺的內容即時產生客製化的 cover letter，不需要你自己寫好放著。

各檔案的用途

Codex 建完後，了解每個檔案做什麼。之後要修改，在 Codex 裡說「幫我改 profile.yml 的目標職位」就好。

檔案用途什麼時候改
cv.md 你的履歷主檔，AI 助手客製化每份申請時的素材庫 換工作、發新論文、學新技能
config/profile.yml 姓名、聯絡方式、目標職位、薪資範圍 改目標職位或薪資期待
portals.yml 要掃描哪些公司的招聘頁，用哪些關鍵字篩選 加新公司或改搜尋關鍵字
modes/_profile.md 你的角色定位、獨特賣點、談薪話術 AI 評估分數不準時微調
article-digest.md 論文和專案的精簡摘要（選填） 有新發表或新專案成果

4. 第一次啟動

在終端機裡，進入 desktop 資料夾：

cd desktop
npm install        # 第一次才需要，安裝前端套件
npm run tauri:dev  # 啟動 app（會自動編譯 Go sidecar）

第一次編譯需要幾分鐘。完成後 app 視窗會自動開啟。

第一次開啟會看到這個畫面：

按下按鈕選擇你的 career-ops 根目錄。如果上一步的檔案都設定好了，就會直接進入主畫面。如果有缺少的檔案，app 會列出來。

以後再開 app，不需要重新選資料夾。app 會記住你上次選的路徑。直接執行 npm run tauri:dev 就好。

5. Pipeline 主畫面

主畫面分成四個區域：

A. 指標列

最上方五個數字，一眼掌握全局：總申請數、平均分、最高分、可行動的數量、已有 PDF 履歷的數量。

B. 工具列

篩選分頁
按狀態篩選。ALL 看全部，TOP ≥4 只看高分職缺。
搜尋
輸入公司名、職稱或備註的關鍵字。
排序
可按分數、日期、公司名、狀態排序。
顯示模式
Grouped 按狀態分組，Flat 單純列表。

C. 申請列表

每一列是一筆申請，點選欄位標頭（Date、Score 等）可以改變排序方向。分數用顏色區分：

≥ 4.2 推薦 ≥ 3.8 可考慮 ≥ 3.0 一般 < 3.0 不建議

每一列的 Status 欄位是下拉選單，可以直接改狀態。可用的狀態：

Interview Offer Responded Applied Evaluated SKIP Rejected Discarded

安全機制：改狀態時，app 會先確認檔案裡的狀態跟你畫面上看到的一致。如果其他工具同時改了同一筆，app 會拒絕寫入並提示你 Reload。每次寫入前都會自動備份到 data/.applications.md.bak。

D. 報告面板

點選列表中任何一列，右側面板會顯示：

  • 公司、職稱、角色類型、遠端政策、薪資估計
  • 「Open job posting」按鈕（在瀏覽器開啟職缺原始連結）
  • 「Open PDF」按鈕（開啟已產生的客製化履歷）
  • 完整的評估報告內容

6. Progress 統計頁面

點選上方導覽列的 Progress 切換到統計頁面。四張卡片各自呈現一個面向：

這些數字全部自動計算，不需要手動更新。每次 Reload 都會重新讀取追蹤表的最新狀態。

7. 日常使用

設定完成後，日常流程大致如下：

AI 助手掃描新職缺
在終端機的 AI 助手裡執行掃描指令，或貼上職缺連結請它評估。AI 助手會自動把結果寫進追蹤表和報告資料夾。
開桌面 app 瀏覽結果
啟動桌面 app（或按 Reload），新的職缺會出現在列表裡。用篩選和排序快速找到最值得投的。
讀報告、決定要不要投
點選任何一列，右邊的報告面板會顯示完整的評估分析。分數 ≥ 4.0 的通常值得認真考慮。
申請後更新狀態
投了履歷後，在列表裡把狀態從 Evaluated 改成 Applied。拿到面試改成 Interview，以此類推。
定期看 Progress 檢視進度
切換到 Progress 頁面，看漏斗轉換率和每週活動量。回應率太低可能要調整目標職位或履歷。

不用擔心資料遺失。所有資料都存在你電腦上的文字檔裡，不上傳任何伺服器。桌面 app 只是讀取和顯示這些檔案。每次改狀態前都會自動備份。

8. 常見問題

app 開不起來，終端機顯示錯誤

先確認四個工具都裝好了（go version、node -v、cargo --version）。最常見的原因是安裝 Rust 後沒有重開終端機，導致 cargo 找不到。關掉終端機重開再試一次。

打開 app 後顯示「not set up yet」

代表你選的資料夾裡缺少必要檔案。畫面上會列出缺少哪些。回到第 3 節，把 cv.md 和 config/profile.yml 建好，然後在 app 裡按 Reload。

列表是空的，一筆資料都沒有

桌面 app 只顯示資料，不產生資料。你需要先用 AI 助手（Claude Code 等）評估至少一個職缺，讓它寫進 data/applications.md 和 reports/。評估完後回到 app 按 Reload。

改狀態時出現「file changed externally」

代表在你上次載入後，其他工具（例如 AI 助手）改了同一筆資料。這是保護機制，防止互相覆蓋。按 Reload 重新載入最新狀態，再改一次就好。

怎麼讓 Codex 評估職缺？

在終端機進入 career-ops 資料夾，開 Codex，直接貼上職缺網址。Codex 會自動評估、產生報告和分數、更新追蹤表。完成後回到桌面 app 按 Reload 就能看到結果。也可以輸入 /career-ops-scan 讓 Codex 自動掃描 portals.yml 裡設定的所有公司。

可以在 Windows 或 Linux 上用嗎？

目前只支援 macOS。Tauri 框架本身跨平台，但這個 app 還沒有在其他系統上測試過。

我的資料會上傳到哪裡嗎？

不會。所有資料只存在你的電腦上。桌面 app 完全離線運作，不連接任何外部伺服器。

怎麼更新 app？

在 desktop 資料夾裡執行 git pull 拉取最新版本，然後重新跑 npm install 和 npm run tauri:dev。你的個人資料（cv.md、profile.yml、applications.md）不會被覆蓋。
