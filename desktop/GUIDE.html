1. CareerOps Desktop 是什麼

CareerOps Desktop 是你的求職助手：集中整理背景資料、分析職缺、尋找新機會、追蹤申請進度，並協助你準備面試。

幫你整理

所有求職工作放在同一處

從履歷資料、職缺分析到申請和面試進度，都可以直接在 App 中處理。

決定權在你

先看建議，再採用

AI 可以幫你分析與起草，但不會替你送出申請、寄信或修改你的資料；每一步都由你確認。

你的資料，你作主：匯入資料與 AI 建議都需要你的確認。CareerOps 不會自行代表你申請工作或聯絡他人。

2. 第一次啟動

第一次開啟 App 時，先選擇一個資料夾來保存你的求職資料。建議使用預設位置；你也可以選擇自己的資料夾。

求職資料夾

你的求職資料放在這裡

macOS 和 Windows 預設都在「文件」中的 CareerOps 資料夾。也可以改用自己的資料夾。

安心使用

App 和資料分開保存

你的履歷、偏好與申請紀錄都保存在你選擇的資料夾。更換或更新 App 不會自動刪除這些資料。

選擇資料夾

直接建立預設資料夾，或選擇你想使用的位置。

開始設定

依照畫面一步一步完成。若暫時沒有文件可匯入，可選 Skip for now，之後再補上。

匯入背景資料

加入履歷與其他職涯資料，確認每份資料的類型。

選擇閱讀語言

決定你想用哪種語言閱讀分析結果與進度摘要。

連接 AI

從畫面列出的可用選項中選擇一個，讓 CareerOps 為你進行分析與起草。

Ready

進入 Home，開始分析一個職缺，或尋找符合條件的新工作。

3. 匯入背景資料

加入能幫助 CareerOps 了解你的資料，例如履歷、作品集、證書、LinkedIn 匯出檔或工作經歷。資料越完整，建議會越貼近你的情況。

選擇類型

幫每份資料標記用途

加入檔案後，確認它是履歷、作品集、證書或其他類型；這能幫助 CareerOps 正確理解內容。

先審閱

你決定是否更新資料

CareerOps 會根據你加入的資料提出建議。你可以逐項查看，只有你選擇採用的內容才會更新你的求職資料。

加入檔案 → 確認類型 → 查看建議 → 選擇採用

拖放檔案或按 Add files。確認每份資料的類型後繼續設定。AI 連接完成後，CareerOps 會整理內容並顯示可更新的建議與資料來源。

請先看每一項建議，再決定是否採用。採用前，你也可以查看將會變更的內容。選擇 Skip for now 不會更新你的求職資料。

PDF 提醒：目前版本可能無法讀取 PDF 裡的文字。若要讓內容用於建立個人資料，請同時提供可選取文字的版本，例如文字檔或文件檔。

4. 選擇語言

你閱讀分析結果的語言，和履歷、求職信等文件的語言可以不同；這樣更符合跨國求職的需求。

閱讀語言

用來顯示分析結果、進度摘要與建議。可在初始設定或 Profile → Job Search 修改。

≠
求職文件語言

CareerOps 會依職缺內容判斷，並用這個語言準備履歷、求職信與面試材料。

例子：你可以用繁體中文閱讀分析結果，同時為德文職缺準備德文履歷與面試材料。

通常 CareerOps 會自動判斷職缺的文件語言。若判斷不正確，可在分析職缺前用 Document language 手動調整。

5. 連接 AI

CareerOps 需要連接一個 AI 服務，才能分析職缺、整理資料與產生準備材料。初始設定時選擇可用服務；之後也能在 Profile → AI 更換。

Ready Not installed Not authenticated Error
選擇可用服務

看到 Ready 就可以使用

從狀態顯示為 Ready 的選項中選一個，即可繼續設定。

日後更換

不用重跑 onboarding

之後可在 Profile → AI 改選其他顯示為 Ready 的服務。

如果顯示 Not authenticated，請依該服務的登入說明完成登入後再試；若顯示 Error，先重新開啟 App。問題持續時，請查看 Help 頁。

6. Home：從這裡開始

Home 是日常入口。上方會顯示你追蹤中的職缺、已申請與面試中的職缺，以及平均匹配分數。主要有兩種開始方式。

Evaluate a job

已經有一個職缺

貼上職缺 URL 或 JD 文字，進入單一職缺分析。

Find matching jobs

讓 CareerOps 幫你找

從設定好的來源執行 Scanner，找出符合條件的新機會。

Home 下方會顯示最近活動，方便你回到 Jobs 查看職缺與申請進度。

7. 分析單一職缺

在 Home 貼上職缺網址或職缺說明後，選擇 Evaluate。CareerOps 會將職缺需求與你的背景、偏好和薪資條件一起分析。

讀取職缺 → 比對你的背景 → 整理工作需求 → 查看薪資資訊 → 提供建議

需要時調整文件語言

預設由 CareerOps 根據職缺內容判斷。若你已知道該使用哪種語言，可直接在 Document language 手動指定。

查看進度

執行期間可在 Agent Activity 查看進度。你可以選擇 Cancel 停止；若失敗，可選 Retry 再試一次。完成後到 Jobs 查看結果與完整分析。

8. 找符合條件的職缺

Scanner 會從你設定的求職來源尋找新職缺，略過重複項目，優先挑出較符合你條件的機會。

搜尋職缺來源 → 略過重複職缺 → 初步篩選 → 分析符合的職缺

掃描完成後按 View results 回到 Jobs，查看找到的職缺與分析結果。

9. Jobs：管理申請

Jobs 是管理所有職缺與申請的地方。你可以搜尋、篩選、排序、查看分析結果，並更新目前進度。

按進度分組

按狀態整理

用看板方式瀏覽職缺。選擇一個職缺後，可直接查看它的分析結果。

表格檢視

快速比較

用表格快速比較、排序與搜尋；選擇後可在旁邊閱讀分析結果。

更新申請進度

當你送出履歷、收到回覆或進入面試時，記得在這裡更新進度，讓 CareerOps 的統計與後續建議保持正確。若資料剛被其他地方更新，請先重新整理再修改。

10. Interview：準備、練習、複盤

當職缺進入面試階段後，會出現在 Interview 頁。你可以依面試進度使用三種工具。

Prep plan

準備計畫

讀取職缺情境，建立面試準備計畫與時間安排。

Practice

模擬練習

產生可能的面試題目與練習材料，幫助你事先演練。

Debrief

面試後複盤

整理面試筆記、找出待加強的地方，為下一輪做準備。

Interview 畫面可設定 Interview language。若你要用特定語言面試，請在開始前確認設定。

11. Progress 與 Profile

Progress

看求職漏斗

查看追蹤中的職缺數量、各階段分布與求職進度統計。

Profile

調整你的設定

在 Profile & Settings 調整背景資料、求職偏好、職缺來源、資料夾位置、AI 與 App 更新。

Profile 區域 用途
My Background 查看你匯入的資料，以及 CareerOps 根據這些資料整理出的個人資料。
Job Search 目標職位、地點、是否接受遠端工作、薪資等偏好，以及閱讀語言。
Search Sources 設定要搜尋的公司與求職網站。
Workspace 查看目前求職資料夾、在檔案管理器開啟它，或切換到另一個資料夾。
AI 查看 AI 服務的連線狀態，並更換目前使用的服務。
About 查看 App 版本，並使用 Check Now 檢查已設定的更新。

求職資料夾

Settings 的 Workspace 區塊會顯示目前位置，並提供 Open Folder 與 Change Location。Open Folder 會在檔案管理器開啟資料夾；Change Location 只會改用另一個資料夾，不會搬移原本的資料。

如果找不到原本的資料夾，例如它被搬移、刪除，或外接硬碟尚未連接，App 會請你重新選擇資料夾。

一般使用不需要技術設定：不需要安裝額外的程式工具。若 App 無法正常啟動或功能持續出錯，請重新安裝或更新 CareerOps Desktop。

12. Help 與疑難排解

Help 頁提供分數、職缺搜尋、AI 使用方式、隱私與常見問題的快速說明。

常見問題

我需要另外開啟其他程式嗎？

不需要。一般情況下，直接在 CareerOps Desktop 裡完成操作即可。

為什麼職缺語言和分析語言不同？

這是刻意設計。閱讀語言是你看分析結果時使用的語言；求職文件語言則依職缺而定。這讓你可以用繁體中文看分析，同時為德文職缺準備德文履歷。

掃描或分析卡住怎麼辦？

先在 Agent Activity 查看目前進度。你可以選 Cancel 後再選 Retry。若仍無法完成，重新開啟 App、確認 AI 服務已登入，或將 App 更新至最新版本。

匯入資料後，AI 會直接改掉我的資料嗎？

不會。AI 只會提出建議。你先逐項查看並選擇要採用的內容，只有你確認的項目才會更新。

資料會傳到 CareerOps 的雲端嗎？

你的求職資料保存在你選擇的資料夾。需要 AI 分析時，資料的傳送與處理方式取決於你選擇的 AI 服務。

安裝與更新：請從 CareerOps 的官方發布頁下載 App。日常更新請使用 App 內的更新提示，或到 About 選擇 Check Now。
